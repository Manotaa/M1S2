This project corresponds to User Story M1S2 – Inventory Control Flow and List Management and was developed in Python to expand the functionality of the basic inventory system by introducing menus, functions, lists, dictionaries, loops, and conditional structures. The application allows users to manage multiple products through an interactive menu where they can add products, display the inventory, calculate statistics, or exit the program. Each product is stored as a dictionary containing its name, price, and quantity, while all products are maintained in a list called inventario. The system includes robust input validation to ensure that prices are numeric and non-negative, quantities are valid integers and non-negative, and menu selections are correctly processed. The program is organized into modular functions, including agregar_producto() for registering products, mostrar_inventario() for displaying all stored items, and calcular_estadisticas() for calculating the total inventory value and the total number of products available. A while loop keeps the application running until the user chooses to exit, while if, elif, and else statements handle menu navigation and invalid options. This implementation demonstrates the practical use of data structures, modular programming, control flow, input validation, loops, and basic inventory statistics, providing a scalable foundation for more advanced inventory management features in subsequent user stories.
